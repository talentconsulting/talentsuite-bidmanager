TalentSuite Bid Manager

TalentSuite Bid Manager is an Aspire-orchestrated bid management application for ingesting, managing, drafting, and reviewing tender responses with a Blazor WebAssembly frontend, ASP.NET Core backend services, background processing, and Azure-hosted platform services.

Open High Level Design Project README

What This Project Contains

  • TalentSuite.AppHost for Aspire local orchestration.
  • src/TalentSuite.FrontEnd for the Blazor WebAssembly user interface.
  • src/TalentSuite.Server for API endpoints, workflow orchestration, and persistence.
  • src/TalentSuite.Functions for asynchronous bid-library and integration work.
